## What is LNKD?

**LNKD** (Linking Nodes in KD-trees) is a computational algorithm that predicts which [reactive atoms](/first-prediction#understanding-reactive-atoms) in a polymer system will form covalent cross-links. It achieves this with **O(n log n)** computational complexity (meaning doubling system size increases runtime by only ~2× instead of 4×) using [KD-tree](/science/algorithm/algorithm-concepts#kd-trees) spatial data structures - dramatically faster than traditional O(n²) pairwise comparison methods.

**Published**: [Journal of Chemical Information and Modeling, 2025](https://pubs.acs.org/doi/10.1021/acs.jcim.5c01376)

## Key Features

<AccordionGroup>
  <Accordion title="Resource Efficient" icon="bolt">
    Uses [KD-tree](/science/algorithm/algorithm-concepts#kd-trees) spatial queries and [max heap](/science/algorithm/algorithm-concepts#priority-queues-max-heap) selection to achieve O(n log n) complexity instead of O(n²) pairwise comparisons.
  </Accordion>

  <Accordion title="High Coverage" icon="bullseye">
    Achieves 88-95% pairing rates of reactive atoms while enforcing chemical constraints. See [validation results](/science/showcase/showcase-gallery#experimental-validation) for experimental confirmation.
  </Accordion>

  <Accordion title="Dual Cross-Linking" icon="link">
    Handles both [radical polymerization](/science/chemistry/radical-polymerization) (C-C bonds) and [azide-alkyne cycloaddition](/science/chemistry/click-chemistry) (click chemistry).
  </Accordion>

  <Accordion title="MINP Modeling" icon="dna">
    Specifically designed for Molecularly Imprinted Nanoparticle (MINP) synthesis workflows.
  </Accordion>
</AccordionGroup>

## Algorithmic Efficiency

LNKD leverages spatial data structures for computational efficiency:

- **Complexity**: O(n log n) neighbor queries vs. O(n²) pairwise comparisons
- **Approach**: KD-tree spatial indexing + greedy max-heap selection
- **Scalability**: Logarithmic scaling enables predictions on large polymer systems

<Tip>
  For detailed performance benchmarks and speedup measurements, see the [published paper](https://pubs.acs.org/doi/10.1021/acs.jcim.5c01376).
</Tip>

## Primary Application: MINPs

LNKD was developed for **Molecularly Imprinted Nanoparticles (MINPs)** - synthetic materials with designed binding sites that mimic biological recognition (like antibodies or enzymes).

## Broader Applications

While designed for MINPs, LNKD applies to any cross-linked polymer system:
- Epoxy resins
- Hydrogels
- Thermoset networks
- Crosslinked elastomers

## Getting Started

<Steps>
  <Step title="Install LNKD">
    Clone the repository and install dependencies
    ```bash
    git clone https://github.com/sdonglab/LNKD.git
    cd LNKD
    pip install -r requirements.txt
    ```
  </Step>

  <Step title="Run Your First Prediction">
    Process a sample structure with reactive atoms defined
    ```bash
    python3 ./pair_prediction/predict_for_single_surfactant.py \
        ./example/input/structure.pdb \
        ./example/input/core_reactive.txt \
        -core_QR 10 -core_W 0.03 \
        ./example/input/sur_reactive.txt \
        -sur_QR 15 -sur_W 0.03 \
        -o ./example/output/
    ```
  </Step>

  <Step title="Explore Results">
    View predicted pairs and unpaired radicals
  </Step>
</Steps>
