    </CodeGroup>

    ```
    Installation successful!
    ```

</Steps>

## Understanding Core vs Surface Cross-Linking

Before running predictions, it's important to understand that LNKD handles two distinct types of cross-linking chemistry:

<Tabs>
  <Tab title="Surface Cross-Linking">
    **Chemistry**: Azide-alkyne cycloaddition (click chemistry)

    **Location**: Surfactant molecules forming the nanoparticle outer shell

    **Reactive atoms**:
    - Azide nitrogens (N₃ groups)
    - Alkyne carbons (C≡C groups)

    **Purpose**: Creates rigid outer shell to confine the core

    **Bond type**: Forms triazole rings (5-membered heterocycles with 2 N-C bonds)

    <Tip>
      Surface parameters typically use larger query radius (15 Å) because click chemistry can form bonds over slightly longer distances.
    </Tip>
  </Tab>

  <Tab title="Core Cross-Linking">
    **Chemistry**: Radical polymerization (C-C bond formation)

    **Location**: Cross-linker molecules (like DVB) inside the nanoparticle

    **Reactive atoms**:
    - Vinyl carbons (C=C double bonds)

    **Purpose**: Densifies the interior network

    **Bond type**: Forms single C-C bonds between radical sites

    <Tip>
      Core parameters typically use smaller query radius (10 Å) for shorter-range radical coupling reactions.
    </Tip>
  </Tab>
</Tabs>

### Why Two Separate Predictions?

These chemistries happen **sequentially** in experimental MINP synthesis:
1. **Surface first**: Cross-link the outer shell
2. **Core second**: Polymerize the interior

LNKD mirrors this process by predicting each chemistry separately with optimized parameters for each reaction type.

<Warning>
  For non-MINP systems with only one cross-linking chemistry, you can use an empty file for the unused chemistry type. See [Extending Reactions](/developer/extending/extending-reactions) for adding new chemistry types.
</Warning>

## Your First Prediction

LNKD comes with a complete example in the `example/` directory. Let's run it:

<Steps>
  <Step title="Navigate to the Repository">
    ```bash
    cd LNKD
    ```
  </Step>

  <Step title="Run the Example Prediction">
    <CodeGroup>
      ```bash Linux/macOS
      python3 ./pair_prediction/predict_for_single_surfactant.py \
          ./example/input/1-PSA_MINP_build1_round2_pair_opt.pdb \
          ./example/input/core_reactive.txt \
          -core_QR 10 \
          -core_W 0.03 \
          ./example/input/sur_reactive.txt \
          -sur_QR 15 \
          -sur_W 0.03 \
          -o ./example/output/
      ```

      ```powershell Windows
      python ./pair_prediction/predict_for_single_surfactant.py ./example/input/1-PSA_MINP_build1_round2_pair_opt.pdb ./example/input/core_reactive.txt -core_QR 10 -core_W 0.03 ./example/input/sur_reactive.txt -sur_QR 15 -sur_W 0.03 -o ./example/output/
      ```
    </CodeGroup>

    <Accordion title="What do these parameters mean?">
      | Parameter | Value | Meaning |
      |-----------|-------|---------|
      | `core_QR` | 10 | **Query Radius** for core: Maximum distance (Angstroms) LNKD searches for potential bonding partners. Atoms farther apart won't be considered. Smaller radius (10 Å) suits short-range radical polymerization. [More →](/first-prediction#query-radius) |
      | `core_W` | 0.03 | **Isolation Weight** for core: Controls preference for bonding to chains with fewer existing bonds (0.0-1.0). Higher values promote uniform cross-linking. Value of 0.03 provides slight preference while maintaining high coverage. [More →](/first-prediction#isolation-weight) |
      | `sur_QR` | 15 | Query Radius for surface: Larger than core (15 Å) because click chemistry can form bonds over slightly longer distances than radical polymerization. |
      | `sur_W` | 0.03 | Isolation Weight for surface: Same principle as core - promotes uniform distribution of surface cross-links. |

      **Why these specific values?** These are recommended starting points based on typical MINP chemistry. Adjust based on your system - see [parameter tuning guide](/first-prediction#choosing-parameters) for details.
    </Accordion>
  </Step>

  <Step title="Check the Output">
    LNKD creates 4 output files in `./example/output/`:

    <CodeGroup>
      ```bash Linux/macOS
      ls -l ./example/output/
      ```

      ```powershell Windows
      dir ./example/output/
      ```
    </CodeGroup>

    **Output files:**
    - `pair_output.txt` - All predicted pairs (core + surface)
    - `core_pair_output.txt` - Core cross-linking pairs only
    - `surface_pair_output.txt` - Surface cross-linking pairs only
    - `radical_output.txt` - Unpaired radicals needing H-saturation
  </Step>

  <Step title="Visualize Results (Optional)">
    Use PyMOL to visualize the predicted bonds:

    ```bash
    pymol ./example/input/1-PSA_MINP_build1_round2_pair_opt.pdb
    ```

    In PyMOL console:
    ```python
    # Load first line of pair_output.txt
    select predicted_pairs, id 59+1054+4602+5222+...
    show sticks, predicted_pairs
    color red, predicted_pairs
    ```

    </Step>
</Steps>

## Understanding the Output

### Pair Output Format

The first line of `pair_output.txt` is a PyMOL selection string:

```
+59+1054+4602+5222+1318+4788+...
```

Subsequent lines list atom pairs:

```
59 1054          # Atom 59 bonds to atom 1054
4602 5222        # Atom 4602 bonds to atom 5222
1318 4788        # ...
```

<Accordion title="Core vs Surface Pairs">
  **Core pairs** ([radical polymerization](/science/chemistry/radical-polymerization)):
  - Single C-C bond formation between vinyl carbons
  - Each line = one C-C bond
  - Example: 137 pairs from the example system

  **Surface pairs** ([click chemistry](/science/chemistry/click-chemistry)):
  - TWO bonds per reaction due to [triazole ring formation](/science/chemistry/click-chemistry#triazole-mechanism)
  - Forms 5-membered heterocycle with two N-C bonds
  - Pairs come in twos in the output file
  - Example: 232 pairs = 116 click reactions (232 ÷ 2 = 116)

  <Tip>
    The distinction between core and surface chemistry is explained in [Understanding Core vs Surface Cross-Linking](#understanding-core-vs-surface-cross-linking) above.
  </Tip>
</Accordion>

### Radical Output

Unpaired reactive carbons ([radicals](/glossary#radical)) are listed by atom serial number:

```
4502
4642
4704
...
```

These atoms require [hydrogen saturation](/glossary#hydrogen-saturation) in post-processing to prevent unrealistic chemistry in MD simulations.

<Tip>
  See [MINP Workflow - Phase 2](/science/workflow/phase-2-crosslinking) for how to use these outputs in MD simulations.
</Tip>

## Troubleshooting

<AccordionGroup>
  <Accordion title="ImportError: No module named 'sklearn'">
    **Solution**: Install scikit-learn
    ```bash
    pip install scikit-learn
    ```
  </Accordion>

  <Accordion title="No pairs predicted (empty output)">
    **Possible causes:**
    1. Query radius too small - increase `-core_QR` or `-sur_QR`
    2. No valid pairs within chemical constraints
    3. Reactive atom definitions don't match PDB atom names

    **Check**: Verify reactive atom file matches your PDB structure
  </Accordion>

  <Accordion title="Very long execution time (>30 seconds)">
    **Possible causes:**
    1. Query radius too large - decrease to 10-15 angstroms
    2. Very large system (>1000 reactive atoms)

    **Optimize**: Start with smaller query radius and increase if coverage is low
  </Accordion>
</AccordionGroup>
